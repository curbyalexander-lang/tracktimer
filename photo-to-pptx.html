Google API Setup
Setup steps:
1. Go to Google Cloud Console and create a project
2. Enable the Google Drive API and Google Picker API
3. Create an API Key (APIs & Services → Credentials → Create Credentials)
4. Create an OAuth 2.0 Client ID (type: Web application)
   • Add http://localhost:8000 (or your serving origin) to Authorized JavaScript Origins
5. Paste both values above and click Save
6. Serve this file via a local server: python3 -m http.server 8000

Local file upload works without any setup.
